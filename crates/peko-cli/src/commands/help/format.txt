peko format - normalize the formatting of Pekoscript files

USAGE
    peko format <file.peko> [more.peko ...] [flags]

DESCRIPTION
    Reprints each file from its parsed syntax tree in canonical form:
    indentation, spacing, and line breaks are all rewritten, and long
    constructs are wrapped to the standard width. Comments are preserved,
    including doc comments and comments inside class, trait, and enum
    bodies. String contents are never altered. By default each file is
    formatted in place.

FLAGS
    --check     Report files that are not formatted and write nothing. Exits
                with a non-zero status when any file would change.
    --stdout    Print the formatted text to stdout instead of writing it back.
