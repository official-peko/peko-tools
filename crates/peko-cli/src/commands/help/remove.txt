peko remove <PACKAGE>

Removes a dependency from peko.toml and re-resolves.

Deletes <PACKAGE> from the [dependencies] table, preserving the file's
formatting, then re-resolves and rewrites peko.lock so the package no longer
appears.

EXAMPLES
    peko remove sockets

OPTIONS
    --global          remove from the global manifest at the Peko root
                      instead of the project

EXAMPLES
    peko remove sockets
    peko remove pekoui --global
